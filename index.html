Turn on live GPS

  
This preview window blocks location, so live recording needs the app on its own web address. It takes about 3 minutes, it's free, and you get a real app icon on your home screen.

  
    
    
  1. Tap Copy app code below. It copies the whole app, including your profile, cars and drives.
    2. 
    
  2. On github.com (free account), tap New repository, name it drivelog, set it to Public, and create it.
    3. 
    
  3. Tap creating a new file, name it index.html, paste, then Commit.
    4. 
    
  4. Go to Settings → Pages. Under Branch pick main and / (root), then Save.
    5. 
    
  5. A minute later, open yourname.github.io/drivelog on your phone, then Share → Add to Home Screen. Allow location when it asks.
    6. 
  

  
While recording, keep the app open and the phone mounted. The screen stays awake on its own. Never touch it while moving.
